# Journey individual module review

This pass treats the 27 Journey modules as 27 different lessons rather than one repeated template.

## Review rules

- Reading should be understandable to roughly a 12-year-old without removing the real skill being taught.
- Everyday words come first. Formal DBT/ACT/CBT terms can still appear when they are useful, but the lesson explains them in plain language.
- Exercises are chosen for the topic. They are no longer the same free-text reflection pattern repeated across the Journey.
- Separate safety/sensitivity warning cards and repeated disclaimers are removed from the module screens. Essential conditions that define a skill stay inside the teaching itself, in normal language.
- Repeated ideas are trimmed where a later module teaches the concept properly.
- The cover remains a short preview, not part of the lesson.
- Exercise answers stay in client state and are not sent with module completion.

## Repetition removed or reduced

- **Building Awareness vs Check the Facts:** camera/narrator teaching now belongs mainly to Check the Facts.
- **Wellbeing vs Reality Acceptance:** Wellbeing only uses acceptance as a starting-point idea; the full skill stays in Reality Acceptance.
- **Choice Points vs Values:** Choice Points is the fork in the moment; Discovering Values is the compass; Values to Action is the planned behaviour.
- **Grounding vs STOP vs ACCEPTS/IMPROVE:** grounding anchors attention, STOP interrupts momentum, and ACCEPTS/IMPROVE helps someone get through a longer rough stretch.
- **Interpersonal overview vs DEAR/GIVE/FAST:** the overview chooses the goal; the next three modules teach a different communication tool for each goal.
- **Coping Ahead vs Personal Commitment Plan:** Coping Ahead prepares for one predictable situation; the final plan pulls several Journey tools together for repeated difficult days.

## Screen simplification

The new renderer removes the previous orange safety-note cards and the repeated footer disclaimers. The module now moves through:

1. a short cover,
2. the number of teaching ideas the topic needs,
3. one knowledge check,
4. one topic-specific interactive exercise,
5. one takeaway screen.

The exercise renderer supports builders, four-part balance boards, single-choice activities, multi-pick toolkits, sorting tasks, applied scenarios and ordered sequences. This lets each module choose the interaction that best teaches the idea instead of forcing every topic into the same reflection form.
